*manager.txt*    Minimal plugin manager for NeoVim   Last Change: 2026-03-01

==============================================================================
INTRODUCTION                                              *manager.nvim*

NeoVim Plugin Manager with Limited Features
It is designed for users who want a minimal but functional way to manage plugins.

==============================================================================

INSTALLATION                                            *manager-install*

To install manager.nvim, add into your `init.lua`:

>lua
    local managerpath = vim.fs.joinpath(vim.fn.stdpath('data'), 'site', 'pack', 'manager', 'start', 'manager.nvim')
    if not (vim.uv or vim.loop).fs_stat(managerpath) then
        local managerrepo = "https://github.com/shizukani-cp/manager.nvim.git"
        vim.fn.system({ "git", "clone", "--filter=blob:none", "--branch=main", managerrepo, managerpath })
        if vim.v.shell_error ~= 0 then
            vim.api.nvim_echo({
                { "Failed to clone manager.nvim:\n", "ErrorMsg" },
            }, true, {})
        end
    end
    vim.opt.runtimepath:prepend(managerpath)
>

You need NeoVim 0.5 or newer and Git installed.

==============================================================================

USAGE                                                   *manager-usage*

To use manager.nvim, load it in your configuration file and add your plugins:

>lua
    local manager = require("manager.core").new()

    manager:add({
        id = "telescope.nvim",
        url = "https://github.com/nvim-telescope/telescope.nvim",
        dependencies = {
            "plenary.nvim",
        },
        config = function()
            -- Write your config here...
        end
    })

    manager:add({
        id = "plenary.nvim",
        url = "https://github.com/nvim-lua/plenary.nvim",
    })

    manager:load("telescope.nvim")
<

Each plugin configuration requires an `id` (unique name) and a `url` (the plugin GitHub repository).
You can specify dependencies and a `config` function to set up your plugin after loading if needed.
To load a plugin, use `manager:load("plugin_id")`.

==============================================================================

FUNCTIONS                                                   *manager-functions*

Manager.new({name})                                     *manager.new()*
    Creates a new instance of the manager.
    `{name}` (string, optional) The name used for the installation
             directory under site/pack/. Defaults to "manager".

manager:add({spec})                                     *manager:add()*
    Registers a plugin. If the plugin is not already installed, it will be
    cloned from its git repository.

    `{spec}` is a table with the following keys:
    `id`           (string, required) A unique identifier for the plugin.
    `url`          (string, required) The URL of the git repository.
    `branch`       (string, optional) The git branch to use. Defaults to the
                   repository's default branch.
    `dependencies` (table, optional) A list of plugin `id`s that this plugin
                   depends on.
    `config`       (function, optional) A function to run after the plugin is
                   loaded.
    `dev`          (boolean, optional) If true, uses local directory.
    `dir`          (string, optional) Path to local plugin for dev mode.

manager:load({id})                                      *manager:load()*
    Loads a plugin and its dependencies. This runs `packadd` and executes
    the `config` function if provided. If a plugin is still being
    installed, it will be loaded automatically after installation is
    complete.

manager:update({id})                                    *manager:update()*
    Updates plugins by pulling the latest changes from their git
    repositories.
    If `{id}` is provided, only that plugin is updated. The special id
    `"self"` will update manager.nvim itself.
    If `{id}` is omitted, all registered plugins are updated.

manager:remove({id})                                    *manager:remove()*
    Removes an installed plugin by deleting its directory. The plugin's
    configuration remains, and it will be re-installed if needed.

manager:clean()                                         *manager:clean()*
    Removes any plugin directories that are no longer registered in your
    configuration. This is useful for cleaning up uninstalled plugins.

==============================================================================

LOGGING                                                     *manager-logging*

Each manager instance has its own logger available at `manager.logger`.

manager.logger:on({callback})                            `manager.logger:on()`
    Registers a callback function that will be called whenever a new
    log entry is added. Returns a function to unregister.

manager.logger:get_logs({level})                    `manager.logger:get_logs()`
    Returns a list of log entries. If `{level}` is provided, filters
    logs by that level (e.g., "INFO", "ERROR").
